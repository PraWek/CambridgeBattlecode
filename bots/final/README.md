# final

Самостоятельный бот: разведка, экономика и логистика из `nexus`, боевая часть из `rc`.
Для запуска или отправки достаточно каталога `bots/final`; импорты исходных ботов не нужны.

```powershell
cambc run final rc maps/arena.map26 --tle 2 --watch
cambc run nexus final maps/default_small1.map26 --tle 2 --watch
```

Ядро сначала выпускает диверсанта RC, затем четырёх строителей Nexus по сторонам света.
С 100-го раунда экономический отряд постепенно растёт до восьми строителей.
Ядро хранит их ID отдельно: пушки, launcher и диверсант не занимают места в квоте рабочих.
Одна проверка ID за ход выявляет потери; уход из видимости не считается гибелью.
Проверка использует ответ движка `Unknown id`; неизвестные ошибки трактуются консервативно.

Строители сохраняют разведку с учётом симметрии карты, распределение месторождений по секторам,
конвейерные линии с контролем пропускной способности, мосты, восстановление повреждений
и поиск пути, распределённый по нескольким ходам. Их алгоритмы взяты из Nexus без изменений.

Диверсант ищет вражеское ядро, выбирает позицию для gunner и прокладывает к нему отдельную
линию снабжения титаном. Сохранены атаки на вражескую логистику, обходы препятствий,
мосты снабжения и переброска через launcher. Боевая навигация RC находится в
`combat_navigation.py`, экономическая навигация Nexus — в `navigation.py`.

Изменения на стыке двух стратегий:

- Диверсант не разбирает и не перенаправляет транспорт других союзных строителей,
  не отбирает снабжение у их действующих шахт. Для атаки он может использовать вражеские шахты.
- Launcher получает конкретную клетку диверсанта; соседний экономический строитель
  не становится случайным пассажиром. Диверсант ждёт завершения начального сканирования launcher.
- Роль и сектор запоминаются до первого сканирования карты, включая повтор инициализации
  после прерывания по CPU. Вражеские маркеры не назначают роли.
- После гибели диверсанта разрешены две замены с интервалом не менее 128 раундов.
  Перед заменой остаётся запас титана на harvester и восемь конвейеров.
  Исходный лимит Nexus на дополнительные экономические спавны сохранён.

Переработка аксионита остаётся выключенной, как в Nexus (`AXIONITE_PIPELINE_ENABLED = False`).
В RC также нет готовой цепочки с foundry, которую можно было бы перенести.

Проверки из корня проекта:

```powershell
.venv/Scripts/python.exe tests/final/run_checks.py
```

Запускаются 50 унаследованных проверок экономики и планирования на модулях `final`,
а также 18 тестов интеграции ролей, спавна, снабжения и launcher.
Артефакты локальных матчей находятся в `tests/final/artifacts` и исключены из Git.
Локальные матчи не заменяют проверку CPU на серверном оборудовании соревнования.
